2. Move (done)

6. Resize via handles
7. ✅ Undo/redo

9. ✅ Input field

25. Import/export JSON
26. Named documents

## Polish
27. ✅ Keyboard shortcuts (R/B/T, Delete, Esc, Ctrl+Z)
