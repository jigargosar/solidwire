# MockBench

MockBench is a wireframing tool designed for speed and semantic clarity. It uses a sketchy, hand-drawn aesthetic to keep the focus on *intent* rather than *pixels*.

## Core Principles

- **Speed of Thought**: As fast as a pencil, as smart as an outline.
- **Deliberate Constraints**: A thinking tool, not a production tool. Low fidelity prevents premature visual polish discussions.
- **Progressive Disclosure**: Depth reveals itself as you reach for it.

## Getting Started

```bash
pnpm install
pnpm dev
```
